# Personal Links Hub 🚀

A centralized, responsive landing page engineered to bridge hardware engineering, software development, and entrepreneurial ventures into a single digital identity.

## 🔗 Live Demo
Check out the live deployment here: [hamzamaqbul-hub.netlify.app](https://hamzamaqbul-hub.netlify.app/)

---

## 🛠️ Built With
* **Structure:** Semantic HTML5
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (via CDN)
* **Hosting:** Netlify
* **Design System:** Custom Dark Navy (`#1F2A44`) & Warm Gold (`#C9A24B`) palette

---

## ✨ Features
* **Mobile-First & Fully Responsive:** Optimized for mobile scanning (QR codes) and desktop screens.
* **Instant Load Times:** Zero build overhead and minimal asset payload.
* **Central Hub Navigation:** Direct gateways to CV download, Portfolio, Mechatronics hardware showcases, and social networks.
